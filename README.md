# Dhrumil Patel Portfolio

A modern, responsive portfolio website built with React and TypeScript.

## Features

- Responsive design that works on all devices
- Dark/Light mode toggle
- Smooth animations and transitions
- Google Analytics integration
- Mouse-following overlay effect

## Tech Stack

- React 19
- TypeScript
- Tailwind CSS
- Modern JavaScript (ES6+)

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or bun

### Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/portfolio.git
cd portfolio
```

2. Install dependencies

```bash
npm install
# or
bun install
```

3. Start the development server

```bash
npm run dev
# or
bun run dev
```

4. Open your browser and navigate to `http://localhost:5173`

## Building for Production

```bash
npm run build
# or
bun run build
```

## Customization

- Update the content in the component files to personalize your portfolio
- Replace the favicon files in the `public/favicon` directory
- Replace `resume.pdf` in the `public` directory with your own resume
